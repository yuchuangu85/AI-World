DeepSeek Agent 架构 · 层级流动动画

数据包怎么穿过 八层架构：看方向、看传递、看返回

下面是一场可控制的动画：一个「数据包」在层与层之间移动。蓝色实心珠 = 请求（下行/上行），绿色虚线珠 = 该边界的响应。 右侧面板同步显示这一跳传递什么、返回什么、为什么这样设计。选一条链路，按播放即可。

① 分层解耦每层只回答一个问题：L1–L4 管「一次轮次怎么跑」，L5–L8 管「多任务怎么协调」。跨层只走契约，不走实现。
② 方向对称请求向下传递「意图 + 依据」，响应向上返回「事实 + 状态」。自由文本不能驱动控制流。
③ 边界契约每一跳都有明确载荷与幂等语义（如 Trigger 内容派生 id、Report 是状态机值），越界要交回而不是硬顶。
