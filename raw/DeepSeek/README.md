## 本地部署

* [Download Ollama on macOS](https://ollama.com/download)
* [deepseek-r1:7b](https://ollama.com/library/deepseek-r1:7b)
* [deepseek-coder:6.7b](https://ollama.com/library/deepseek-coder:6.7b)
* [在mac与ubuntu上部署DeepSeek-R1模型 & 7b和32b模型的简单对比测试 | 所念皆星河](https://immortalqx.github.io/2025/01/28/deepseek-r1-deploy/)

### 指令

```
// 部署模型
ollama run deepseek-r1:32b

// 删除模型
ollama rm deepseek-coder:6.7b
```

后面的32B是自己配置的，可以是：1.5B，7B， 8B，14B，32B，70B，671B
