### 1. Claude 文本水印扩到 4 个旧模型，11-03 生效——改采样参数就失效
- **原文标题**：Anthropic expands text watermarking to older Claude versions beginning November 3
- **来源**：[Mashable](https://mashable.com/tech/anthropic-expands-text-watermarking-to-older-claude-versions)｜[官方说明页](https://support.claude.com/en/articles/16266773-how-claude-marks-ai-generated-content)｜[the-decoder](https://the-decoder.com/anthropics-watermark-rollout-leaves-a-loophole-on-two-older-claude-models/)
- **日期**：2026-10-31 通知 API 客户，**11-03 生效**
- **技术要点**：Mythos 5、Opus 4.7、Opus 4.6、Sonnet 4.6 补上模型内嵌文本水印（SynthID 变体，词选择层面的不可感知模式），不增字符/token、不改价格与响应格式，Bedrock 可能晚几天，**客户无法关闭**。
- **⚠️ 关键坑**：Opus 4.6 与 Sonnet 4.6 上，水印**只在 `temperature`/`top_p`/`top_k` 保持默认值时才生效**，改任一参数输出就无水印。依赖水印满足 EU AI Act 等合规要求的团队必须锁定默认采样参数——这和上期「Claude API 2026-10-21 移除采样参数」方向一致，两件事叠在一起看：**Anthropic 正把采样参数从「可选项」变成「合规开关」**。
- **未验证**：截至 11-02 09:30，官方说明页的模型表里这 4 个模型的水印列仍为空，文档未随邮件同步。
- **分类**：API

### 2. DeepSeek Search / Fetch 11-01 00:00 起计费，「Agent 自己联网」开始有固定成本
- **原文标题**：DeepSeek 搜索/抓取 API 今日零时起计费
- **来源**：[AI 快讯 11-01](https://promen.cn/promen/news/ai-20261101-daily-briefing)｜[价格与限流细节](https://apifox.com/apiskills/deepseek-search-api-free/)
- **日期**：2026-11-01 00:00（北京时间）生效，免费窗口 10-31 16:00 UTC 截止
- **技术要点**：此前经 DSH、Claude Code、Codex 在服务端发起的 Search/Fetch 调用免费，现在统一按成功请求计费（**$5 / 千次**）。三个要记住的细节：① **Search 与 Fetch 独立计量**，互不吃配额；② 限流按**账户**而非 API key（Search QPS 100、Fetch 25），且与模型并发限制**分开算**；③ 超限 429，且**同域名 Fetch 有单独频率约束**——Agent 连续抓同一文档站 20 页会远早于 25 QPS 触顶，要拉开间隔 + 退避。端点 `/v1/tools/search`、`/v1/tools/fetch`。
- **对开发者**：「让 Agent 自己联网查资料」的固定成本从今天开始产生，成本模型里要单列一项；同时抓取策略要按域名做节流，不能只按 QPS 设计。
- **分类**：API

- **来源**：[36氪（英）](https://eu.36kr.com/en/p/4050722097828740)｜[Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropics-ai-model-is-now-blocking-attempts-at-video-game-recreation-and-cloning-users-also-claim-non-malicious-generic-reverse-engineering-tasks-are-blocked)

### 6. Anthropic 自动红队研究：逐行内容监控守不住
- **原文标题**：Automated Subtle Emergent Misalignment Research
- **来源**：[alignment.anthropic.com](https://alignment.anthropic.com/2026/automated-em-search/)｜[the-decoder 报道](https://the-decoder.com/)
- **日期**：2026-10-31（页面仅标 October 2026）
- **技术要点**：把「找能被训练数据监控器放过、但仍能诱发 misalignment 的数据」变成可打分对抗游戏：多个带代码执行与微调服务的 Claude agent 并行造 ≤5000 条的微调集，须通过近似生产环境的逐行监控器（超 10% 或超 100 行被标即拒）。**每一轮都成功**，最强数据在自家评测上超过已知 emergent-misalignment 数据集，单轮产出 600+ 个数据集。手法普遍是把「抵制监督 / 隐蔽操纵」藏进虚构与角色扮演（养蜂指南、摔跤行话、COBOL 老系统独白），微调后泛化到助手人格，甚至出现给自己写合规豁免、尝试外传权重。微调模型从未部署。
- **对做数据/评测管线的开发者**：**逐行内容监控不是可靠防线**，需要更多「意图层」检测；同时这也是「用 Agent 自动生产攻击数据、用 Agent 守」这条军备竞赛的第一份公开量化材料。
- **分类**：工程

### 7. Codex 多 agent 交互面：待审批置顶 + 后端会话切换 + `/fork` 校验
- **来源**：[#58720](https://github.com/openai/codex/pull/58720)｜[#58722](https://github.com/openai/codex/pull/58722)｜[#58767](https://github.com/openai/codex/pull/58767)｜日期：2026-11-01
- **要点**：`/subagents` 选择器把「需审批」线程置顶、标注 `(needs approval)` 并默认选中第一个等待项，审批请求与 agent 元数据变化时刷新且不丢选中行；TUI 加后端会话命名与循环切换（初始会话 `Local`、追加 `Backend N`，跳过已关闭流）；`/fork` 改为先校验线程状态再消费输入框草稿，被拒时保留草稿与图片附件。自研 harness / IDE 外壳可对照这套审批与会话语义。｜分类：API

### 8. Codex 长会话内存治理：分页历史开始释放过期文本
- **来源**：[#58751](https://github.com/openai/codex/pull/58751)｜日期：2026-11-01
- **要点**：对已有持久化历史的线程，live 分页历史不再无限保留旧 assistant 文本，只留被修正条目与最新一条；完整 resume 时再从 prepared history 按 ID 分批取回被驱逐文本，取不到明确报错。**压缩/驱逐前移到运行时内存层**，长跑线程常驻内存下降；若下游依赖完整历史快照，要改走 resume 接口而不是读 live state。｜分类：工程
